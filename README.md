# Task Manager (Менеджер задач)

Простое и удобное десктопное приложение для управления задачами и контроля сроков их выполнения.

![Скриншот интерфейса](https://i.pinimg.com/736x/80/cf/e2/80cfe2058d640abfd55cf8c1dfdcca3c.jpg) 

![Скриншот интерфейса](https://i.pinimg.com/736x/d9/01/60/d90160a328e168dd5ebaba7fc428be37.jpg) 


## Функциональность

*   **Создание и редактирование задач:** Укажите название, описание, срок исполнения и приоритет.
*   **Наглядное отображение:** Все задачи отображаются в удобном списке с цветовой индикацией приближающихся дедлайнов.
*   **Надежное хранение:** Все данные сохраняются в локальную базу данных.

## Технологии

*   **Язык:** Python
*   **GUI:** PySide6 (Qt для Python)
*   **База данных:** SQLite
*   **ORM:** SQLAlchemy

## Установка и запуск

1.  Убедитесь, что у вас установлен Python 3.8 или выше.
2.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/dis28kiki/Kyrsov_2025.git
    ```
3.  Перейдите в папку проекта и установите зависимости:
    ```bash
    cd Kyrsov_2025
    pip install -r requirements.txt
    ```
4.  Запустите приложение:
    ```bash
    python deadline.py
    ```
